## Attribution note

The source files were downloaded without retaining their individual Unsplash
photo-page URLs or photographer bylines, and the downloaded JPEGs contain no
source metadata. The Unsplash License does not require attribution, but the
individual source pages should be recovered or the images replaced with
commissioned/cleared photography before launch. Do not add photographer names
or source URLs to this file unless they are verified against the original
photo pages.

## Rules for these assets

- Do not describe the homes, neighborhoods, prices, or features as real.
- Do not crop a photo into a claim about a specific address.
- If an asset is replaced, update this table and re-check its licence before
  committing it.
